ngitflow brings Git Flow branch management and semantic versioning together in a simple command-line tool for Node.js projects. It handles the full release and feature lifecycle — from creating branches to bumping versions, committing changes, and pushing tags — so you can focus on writing code.

## How it works

ngitflow wraps `git-flow` (AVH Edition) with automatic `package.json` version management. Every branch operation — starting a release, finishing a feature — is paired with a semver bump and a commit so your version history stays clean.

<Steps>
  <Step title="Install ngitflow">
    Add ngitflow to your project or install it globally with npm.

    ```bash
    npm install --save-dev ngitflow
    ```
  </Step>
  <Step title="Initialize your repository">
    Set up the Git Flow branch structure (`master` and `develop`) in one command.

    ```bash
    npx ngitflow init
    ```
  </Step>
  <Step title="Start a release">
    Create a release branch and bump the version automatically.

    ```bash
    npx ngitflow release start
    ```
  </Step>
  <Step title="Finish the release">
    Merge back to `master` and `develop`, tag the release, and push.

    ```bash
    npx ngitflow release finish
    ```
  </Step>
</Steps>
